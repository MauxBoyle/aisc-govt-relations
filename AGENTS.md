# Repository Instructions

## Issue Work

- Never create, modify, move, or delete files while the current Git branch is
  `main` when working on an issue.
- Before making any file changes for issue work, verify the current branch. If
  it is `main`, create or switch to the branch named in the approved plan.
- If the plan does not name a branch, that branch cannot be created, or
  existing uncommitted changes make switching unsafe, stop and ask the user how
  they want to proceed. Do not write any files on `main`.
